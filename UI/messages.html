Automated vendor messages

Cyrix Bot
Nobody on the team writes to vendors by hand. The Cyrix bot sends the quotation request, chases the vendor with automatic follow-ups (24 h, 48 h and 72 h), reads the reply and records the quote. If there is still no answer after the third follow-up, it flags the PI owner. This thread is a representative preview built from the real PI and vendor data.
